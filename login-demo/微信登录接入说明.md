# 微信登录接入说明（个人开发者版）

> 记录时间：2026-10 · 面向本仓库 `login-demo` 的配套说明
> 微信政策会调整，最终以开放平台 / 公众平台后台的实际提示为准。

---

## 0. 一句话结论

| 你想要的形态 | 个人身份能不能做 |
| --- | --- |
| 网页上出现二维码，用户用微信扫一下就登录 | ❌ 不能（需企业 / 个体工商户主体） |
| 小程序里用微信身份登录，或 PC 出「小程序码」扫码登录 | ✅ 能（个人主体小程序，免费） |
| 微信内打开的 H5 用微信身份登录 | ⚠️ 只能先用「测试号」验证，正式要服务号（企业） |

个人身份拿不到「网站应用 · 微信登录」这个能力，卡点在**主体资质认证**，不在代码。

---

## 1. 三种形态对比

| 方案 | 真微信身份 | 入口 | 主体要求 | 费用 | 上手时间 |
| --- | --- | --- | --- | --- | --- |
| **A. 个人小程序** | ✅ 真 openid | 小程序内 / PC 出小程序码 | 个人身份证 | 0 元 | 1–3 天（含注册） |
| **B. 公众号测试号** | ✅ 真 openid | 微信内 H5 | 无 | 0 元 | 10 分钟 |
| **C. 个体户 + 开放平台认证** | ✅ 真 openid | **网页二维码扫码** | 个体工商户 / 企业 | 认证 300 元/年 | 2–4 周 |

推荐顺序：练手 → B 或 A；要正式产品且必须是网页扫码 → C。

## 2. 为什么个人做不了「网页扫码登录」

微信的网页扫码登录走「网站应用」，官方流程（[开发指南](https://developers.weixin.qq.com/doc/oplatform/Website_App/WeChat_Login/Wechat_Login.html)）：

1. 注册微信开放平台开发者账号
2. 创建「网站应用」并通过审核
3. 开通「微信登录」能力，拿到 AppID / AppSecret
4. 配置授权回调域，用 `qrconnect` 或 `WxLogin.js` 出二维码

关键门槛在**开发者资质认证**：

- 认证要营业执照（企业或个体工商户），个人身份证主体无法完成
- 官方在[业务域名配置文档](https://developers.weixin.qq.com/doc/oplatform/Website_App/guide/domain.html)里明确以「已通过认证的开放平台账号」为前提
- 网站应用审核还要求：官网可访问、有 ICP 备案号、主体信息与认证主体一致、有功能说明 / 用户协议 / 联系方式（见[应用审核规范](https://developers.weixin.qq.com/doc/oplatform/Website_App/operation.html)）

所以：**不是技术上难，是资质上过不去。**

## 3. 方案 A：个人主体小程序（个人开发者的现实解）

### 3.1 能做什么

- 小程序内 `wx.login()` 拿到 `code`，服务端换 `openid`（真实微信身份）
- PC 页面展示**小程序码**，用户扫码 → 小程序授权 → PC 轮询完成登录
- 体验非常接近网页扫码，只是中间多了一步「进入小程序」

### 3.2 成本与时间

| 项目 | 说明 |
| --- | --- |
| 注册 | 免费，身份证 + 未注册过微信生态的邮箱 |
| 认证 | 不需要（个人主体本来也不能做微信认证） |
| 备案 | 发布前必须做，开发调试阶段不用等 |
| 时间 | 注册约 10 分钟；开发版调试 1 天内可跑通 |

### 3.3 注册步骤

1. [mp.weixin.qq.com](https://mp.weixin.qq.com) → 立即注册 → 选「小程序」
2. 填邮箱 + 密码，去邮箱点激活链接
3. 主体类型选「个人」，填身份证信息，管理员微信扫码验证（可能有人脸识别）
4. 填小程序名称 / 头像 / 简介 / 服务类目（个人只能选有限类目，「工具」类即可）
5. 后台 → 开发管理 → 开发设置：复制 **AppID**；点「生成」拿 **AppSecret**（只显示一次）

### 3.4 登录链路

```
PC 浏览器                服务端                      微信服务器
   │ POST /login/mini/ticket │                          │
   │────────────────────────>│ cgi-bin/token            │
   │                         │─────────────────────────>│
   │                         │ wxa/getwxacodeunlimit     │
   │                         │─────────────────────────>│
   │<── 小程序码 + 票据 id ───│                          │
   │                         │                          │
   │      （手机扫码，打开小程序）                        │
   │                         │<── POST /mini/confirm ───│ 小程序 wx.login
   │                         │ sns/jscode2session       │
   │                         │─────────────────────────>│
   │                         │<── openid + session_key ─│
   │<── 轮询：confirmed + code│                          │
   │ POST /mini/exchange     │ 消费一次性 code           │
   │────────────────────────>│                          │
   │<── Set-Cookie + openid ─│                          │
```

要点：

- `session_key` 只留在服务端内存，不下发前端、不落库
- `code` 一次性 + 5 分钟过期（微信语义），本项目按同样规则实现
- 小程序码用 `env_version` 控制打开开发版 / 体验版 / 正式版

### 3.5 限制（都是资质带来的，不是代码问题）

| 限制 | 说明 |
| --- | --- |
| **没有 unionid** | 绑定开放平台需要企业/个体户；个人小程序只有 openid |
| 不能接微信支付 | 个人主体不支持 |
| 开发版有身份限制 | 扫码者必须是小程序项目成员（你自己就是） |
| 真机走 http 要开调试 | 正式环境必须 https + 合法域名 |
| 对外发布要备案 | 小程序备案，约 1–20 个工作日 |
| openid 不能跨应用 | 只在你自己的小程序内有效 |

## 4. 方案 B：公众号测试号（最快看到真实 openid）

- 地址：[mp.weixin.qq.com/debug/cgi-bin/sandbox?t=sandbox/login](https://mp.weixin.qq.com/debug/cgi-bin/sandbox?t=sandbox/login)
- 微信扫码即得 appID / appsecret，可配置网页授权回调、体验用户
- 实测能拿到真实 openid / unionid
- **限制**：只能微信内打开 H5，不能做 PC 扫码；测试号不能用于生产

适合：想在 10 分钟内确认「服务端换 openid」这条链路是通的。

## 5. 方案 C：个体工商户 + 开放平台认证（要网页扫码才走）

### 5.1 四道门槛

| 阶段 | 要求 | 时间 |
| --- | --- | --- |
| ① 个体户执照 | 身份证、经营场所（可用住所申报 / 网络经营场所，各地不同）、名称、经营范围 | 1–3 天 |
| ② 域名备案 | **必须用个体户主体备案**（与认证主体一致），境内服务器 | 7–20 天 |
| ③ 开放平台认证 | 营业执照、经营者身份证、盖章认证公函、银行账户验证，300 元/年 | 1–5 天 |
| ④ 网站应用 + 微信登录 | 官网内容规范、类目、回调域（https + 校验文件）、审核 | 1–7 天，可能返工 |

### 5.2 成本

| 项目 | 费用 |
| --- | --- |
| 个体户执照 | 0（自办）～800（代办） |
| 刻章 | 0～200 |
| 域名 | 30～100/年 |
| 云服务器 | 100～400/年 |
| 开放平台认证 | **300 元/年**（到期续费同价） |
| 首年合计 | 约 450～1500 元 |

### 5.3 六个常见卡点

1. **主体不一致**：个人备案域名 + 个体户认证主体，必驳回
2. **官网太薄**：只有登录页 / 一张图 / H5，必驳回
3. **回调域不精确**：`www` 与裸域、端口、路径后缀都会导致「该链接无法访问」
4. **域名未实名或备案未下就提审**
5. **认证到期忘续费**：能力被收回，用户登录直接失败
6. **个体户不年报（每年 1–6 月）、不报税**：进经营异常，影响续期

### 5.4 在职员工能不能办个体户

- 法律上可以（市监局不查在职），但受三类约束：
  - **公务员 / 参公人员 / 现役军人**：禁止经商办企业
  - **国企、事业单位领导及部分岗位**：内部规定普遍禁止
  - **普通企业员工**：看劳动合同与员工手册的兼职、竞业条款；经营范围避开公司主业，不用公司资源
- 个体户是**无限责任**，网站出问题由个人财产承担
- 不建议用亲属名义代持

## 6. 本仓库的 `login-demo`

### 6.1 能力

- **真微信模式**（配置小程序 AppID 后自动启用）：真小程序码 + 轮询 + 真 openid
- **模拟模式**（未配置时兜底）：完整状态机，本地假身份
- **GitHub OAuth**：真实协议，`state` 防 CSRF

### 6.2 运行

```powershell
cd login-demo
pnpm dev        # http://127.0.0.1:5180
```

### 6.3 已验证的事实

- 用**假 AppID** 调真实微信接口 → 返回 `40013 invalid appid`，证明链路通到 `api.weixin.qq.com`
- 用**真 AppID** 成功生成 280×280 的小程序码（JPEG），票据 5 分钟有效
- 模拟模式全链路：创建票据 → 扫码 → 确认 → 一次性 code → 会话 → 重放被拒（`40163 code been used`）
- 浏览器端无控制台报错、无横向溢出，手机确认页可交互

### 6.4 当前进度（2026-10-21）

| 项 | 状态 |
| --- | --- |
| `.env` 填 AppID / AppSecret | ✅ |
| 真实小程序码生成 | ✅ |
| 小程序代码 `login-demo/miniprogram/` | ✅ 已写好 |
| 微信开发者工具导入 + 编译 / 上传 | ⏳ 待做 |
| 真机扫码（局域网 + 调试模式） | ⏳ 待做 |

**只差最后一步**：在微信开发者工具里导入 `login-demo/miniprogram`、填 AppID、编译（或上传）一次。

### 6.5 换成真微信要改的地方

- `server/wechat-mini.ts`：三处微信接口地址与参数（token / 小程序码 / code2Session）
- `server/api.ts`：`/api/login/mini/*` 三个路由
- `miniprogram/config.js`：`apiBase`（真机改成局域网 IP）

## 7. 常见报错对照

| 现象 | 原因 |
| --- | --- |
| `40013 invalid appid` | AppID 错误，或与 Secret 不匹配 |
| `40125 invalid appsecret` | Secret 错误，需重置 |
| `41030 invalid page` | `WX_MINI_PAGE` 指向页面不存在 |
| 扫码提示「该小程序未发布 / 无权限」 | 开发版未上传，或扫码者不是项目成员 |
| 小程序内「网络失败」 | `apiBase` 错 / 不在同一局域网 / 未开调试模式 |
| 页面显示「模拟模式」 | `.env` 未填或未重启 |
| 网站应用审核要求「备案信息与主体一致」 | 用个人备案配了个体户认证 |

## 8. 合规红线

- **不要借别人的 AppID**，也不要用「代接微信登录」的第三方服务：违反平台规则、回调域校验过不去、用户 openid 会经过第三方
- **openid 只在单个应用内唯一**，跨应用必须用 unionid（个人拿不到，这是能力边界）
- **session_key 不落库、不返回前端**
- **个人备案的网站不能经营**，要商用就该用个体户/企业主体备案

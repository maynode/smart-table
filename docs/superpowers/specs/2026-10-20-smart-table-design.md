> 日期：2026-10-20（修订：去掉飞书对标，专做企微智能表格能力）  
> 状态：**终审锁定**（2026-10-20；Acceptance Matrix A1–A22 + X1；无缩水包；可开工）  
> 依据：`docs/智能表格-产品与技术方案.md`、`docs/superpowers/plans/2026-10-20-phase0-1-core-serial-claim.md`、`docs/design-refs/wecom/`

---

## 1. 意图与为什么

做一款**企业私有化部署**的智能表格：能力与交互**唯一对标企业微信智能表格**，在同等功能上补强弱项，性能可扩展到超大规模。

**相对企微必须更强：**

1. 自动化「只处理 N 条（默认 1）」  
2. 表单成功页可展示动态字段（如序列号）  
3. 并发占码原子安全  

**不做：** 不以飞书多维表格、Airtable 为对标或体验目标。

---

## 2. 目标 / 非目标 / 反目标

### 2.1 目标

| 类别 | 内容 |
|------|------|
| 产品形态 | 私有化；一套环境服务一家企业（或集团） |
| 组织模型 | 多工作区（子公司/事业部）；默认隔离；可授权共享；可对外公开 |
| 对外公开 | 公开填表 + 公开只读视图（可密码/有效期）；**不做**可编辑公网外链 |
| 能力边界 | **企微智能表格已有能力全集**（见截图与方案 §2–§3）；另加上述三项必补强弱项；**Task 1–26 一次交齐** |
| 体验 | **像企微智能表格**：顶栏 + 左侧对象/新建 + 主区表格/表单；普通人能上手 |
| UI 参照 | `docs/design-refs/wecom/smart-table/` + `dashboard/`（分类存放，勿混） |
| 登录 | 账号密码 + 企微 OAuth（可配置关闭，**实现必有**） |
| 性能北星 | 百万级并发填表可扩展；单表千万行顺滑；体感明显快过企微智能表格 |
| 部署 | Docker Compose + Kubernetes 都支持；同一套产品，功能不缩水 |
| 研发 | 自研；开源多维表仅技术参照，不 fork |

技术栈（与方案 §5.1 / 实施计划 Tech Stack 一致，禁止降级）：Vue 3 + **多层 Canvas** + HyperFormula；NestJS + **Fastify**；PostgreSQL 16+ + **PgBouncer**；Redis + BullMQ；MinIO；ECharts；argon2id；OpenTelemetry；Compose + K8s YAML。monorepo：`apps/web`、`apps/api`、`packages/shared`。

### 2.2 非目标（永不做 / 不做进产品）

- CRDT 多人实时编辑  
- 插件市场  
- 多区域多活  
- 可编辑公网外链（公开填表 + 公开只读可以；可编辑外链不做）  

**注意：** 企微 OAuth、跨空间共享、公开只读、Open API、同步、审计配额、压测达标 —— **全部在实施计划内交付，不是非目标。**

### 2.3 反目标

- 再引入飞书/Airtable 作为产品标杆导致范围漂移  
- 做成「先弱版再优化」或把能力标成「后续」变相缩水  
- 界面不像企微、业务用户不会用  
- 差异点（成功页变量、limit=1、占码）做不干净

## 3. 约束

| 约束 | 说明 |
|------|------|
| 功能与性能不准妥协 | Task 顺序 = 建造顺序，≠ 砍需求或降 SLO；禁止「后续缩水包」 |

| 百万并发验收 | 「给定 K8s 规格下，压测可持续高峰提交并达标」；具体 QPS/时长写入 `PERFORMANCE.md`，不是单机开箱百万 |

## 4. 信息架构与权限（对齐企微）

```
Installation
 └── Workspace × N
      └── Base / 文档
           ├── Sheet（工作表，如「码库」）
           ├── Form（收集表单）
           ├── Automation
           ├── Dashboard / 分析报告
           └── Folder
```

顶栏：成员、分享、内容权限、自动化、更多。  
侧栏：对象列表 + 新建（工作表/仪表盘/收集表单/分析报告/文件夹/导入/同步/模板）。  
主区：表格工具栏（添加行、表格设置、筛选、分组、排序、行高、填色）或表单编辑/填写。

权限：默认工作区隔离；可授权共享；内容权限按对象配置全员/指定成员；表单可对企业内外开放填写。

## 5. 能力地图（封闭范围）

以企微截图为准，摘要：

- 字段类型清单（文本…公式/查找引用/系统字段等，见 `01-field-types`）  
- 表格视图与表格设置  
- 收集表单编辑/填写/分享  
- 自动化列表、自然语言步骤、查找/修改/发消息、运行日志、月额度展示（必做）  
- 内容权限  
- 仪表盘/分析、导入、同步、模板（**全部本计划交付**）  

**额外必做（超企微短板）：** 成功页字段变量、`FindRecords.limit` 默认 1、占码事务、同手机号不可重复领（可配）。  
**明确不做：** 短信验证码（见方案 §8）。

---

## 6. 性能与部署

- 无状态 API、PgBouncer、BullMQ、可分片/分区演进  
- **多层 Canvas** 双向虚拟化 + cursor 窗口拉取（禁止 DOM 全表）  
- Docker 单机完整功能；K8s YAML 扩到性能北星  
- 公开表单：短事务占码 + sync/queue；成功页同步或轮询；**公开提交限流**  
- **压测达标报告在本计划 Task 26 完成**，不得外推  

---

## 7. 建造顺序

仅 Task 1→26 的实现顺序（见实施计划）。**无「二期产品范围」。**

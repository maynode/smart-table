# 智能表格 — 产品与技术方案

> 独立产品方案。唯一产品对标：**企业微信智能表格 + 仪表盘**；私有化部署；在同等能力上补强弱项并做到更高性能。交互以 `docs/design-refs/wecom/` 为准（`smart-table/` 与 `dashboard/` 分开存放，勿混用）。

---

## 1. 定位

| 项 | 说明 |
|----|------|
| 产品形态 | 企业**私有化部署**的智能表格（多维表） |
| 主对标 | **企业微信智能表格**（能力与交互唯一标杆） |
| 不做 | 不以飞书多维表格、Airtable 为对标或体验目标 |
| 相对企微必须更强 | ① 自动化「只处理 N 条（默认 1）」② 表单成功页可展示动态字段（如序列号）③ 并发占码原子安全 ④ 性能可扩展（百万并发填表、千万行顺滑） |

**能力关系：**  
「表格 + 收集表单 + 自动化 + 成功页动态结果」是验收主路径；内容权限、仪表盘/分析、导入同步、模板、开放 API、跨空间共享等与主路径**同一交付计划**，不以「底座先上、平台以后」拆包。

## 2. 竞品对标

只深挖 **企业微信智能表格 + 仪表盘**。截图：`docs/design-refs/wecom/smart-table/`、`.../dashboard/`、`.../shared/`。

| 模块（来自截图） | 对标要点 |
|------------------|----------|
| 工作表 / 码库网格 | 添加行、表格设置、筛选/分组/排序/行高/填色、字段类型图标、记录数 |
| 字段类型 | 文本、单选/多选、数字、百分数、货币、进度、日期、人员、群聊、图片、文件、关联、链接、电话、邮箱、地理位置、复选框、条码、自动编号、公式、查找引用、创建人/时间等系统字段；可有 AI 字段入口 |
| 收集表单 | 编辑表单 / 填写表单；分享表单（启用链接、填写范围、复制链接/二维码/转发） |
| 自动化 | 流程列表、月额度、自然语言步骤卡片；触发（新增记录+条件）→ 查找记录 → 修改/发消息；步骤变量；运行日志 |
| 内容权限 | 全员权限按对象（工作表/表单/报告）；可为指定成员加额外权限 |
| 侧栏新建 | 工作表、仪表盘、收集表单、分析报告、文件夹、导入表格、同步数据、从模板新建 |

**开源项目**仅作技术实现参照（Baserow 等），不改变产品对标对象；不 fork 改皮上线。

## 3. 能力地图

### 3.1 核心底座（对齐企微 + 必补强弱项）

| 模块 | 能力 |
|------|------|
| 文档 / Base | 多工作区、多文档（Base）、多工作表、文件夹、模板 |
| 字段类型 | 与企微智能表格字段集对齐（见 §2）；**截图清单全量可创建/存储/展示**（公式经 HyperFormula） |
| 表格视图 | 增删改行、筛选 / 分组 / 排序 / 行高 / 条件填色、表格设置（字段显隐） |
| 收集表单 | 编辑/填写预览；分享链接/二维码；填写范围；**成功页自定义文案与字段变量** |
| 自动化 | 触发（新增等）+ 条件；查找 / 修改 / 发消息等；**查找 `limit` 默认 1**；修改绑定上一步结果；运行日志；步骤变量 |

### 3.2 平台能力（与底座同一交付计划，不后置）

| 模块 | 能力 |
|------|------|
| 内容权限 | 对象级权限；指定成员额外权限；工作区隔离 + 可授权共享 + 对外公开 |
| 仪表盘 / 分析报告 | 图表与指标（对齐企微侧栏能力） |
| 导入 / 同步 | 导入表格、同步数据 |
| 开放能力 | REST API、Webhook、Excel 导入导出（私有化增强） |
| 审计与用量 | 操作审计、自动化运行次数、存储等配额（管理员策略） |
| 登录 | 账号密码 + 企微 OAuth（可配置关闭，实现必有） |

### 3.3 官方场景模板（验收用）

内置 **「序列号 / 兑换码发放」**（与当前企微测试文档场景一致）：

- 收集表单提交 → 码库查找未领码（limit=1）并占用  
- **成功页直接展示序列号**（不依赖站内信）  
- 并发不重码；码发完明确提示  
- 可配置：同手机号不可重复领

## 5. 技术架构

### 5.1 推荐选型（业界顶尖档，详见实施计划 Tech Stack）

| 层 | 选型 |
|----|------|
| 前端 | Vue 3 + TypeScript + Vite；**多层 Canvas 网格**（双向虚拟化；DOM 仅编辑浮层） |
| 公式 | HyperFormula |
| 后端 | NestJS + **Fastify** + TypeScript；占码独立 worker + raw SQL |
| 主库 | PostgreSQL 16+ + **PgBouncer** |
| 缓存 / 队列 | Redis + BullMQ（可演进 Kafka/Streams） |
| 文件 | S3 兼容（MinIO） |
| 图表 | Apache ECharts；`AnalyticsQueryPort`（PG 聚合默认实现 + **ClickHouse 适配器本计划交付**，compose profile 可开） |
| 密码 | argon2id |
| 可观测 | OpenTelemetry |
| 部署 | Docker Compose + Kubernetes（真实 YAML）；同一套产品 |

monorepo：`apps/web`、`apps/api`、`packages/shared`。  

**说明：** 「最佳」= 在**私有化、开源可交付、千万行网格、高峰填表**约束下的业界顶尖组合，不是每个名词都挂「全球唯一第一」。禁止用明显劣一档替代。

### 5.2 核心模型（概念）

- **Record**：`{ id, sheetId, cells, version, claim_status? }`（JSONB + 可索引旁路列）  
- **Form**：字段映射 + `successPage`（`{{field}}`）+ share（启用/范围/过期/二维码）  
- **Automation**：`trigger` + `steps[]`；`FindRecords.limit` 默认 **1**；修改可绑 `fromStep`  
- **占码**：独立 worker + 同事务 `SELECT … FOR UPDATE SKIP LOCKED`  
- **成功页 values**：`formCells ∪ stepOutputs`（自动化覆盖）  

### 5.3 表单 → 自动化 → 成功页

```
提交表单（限流）→ 写记录 → 自动化（sync 或 queue+轮询）
  → 查找未领码 limit=1 并 SKIP LOCKED 占用 → 回写
  → 成功页渲染 merge 后的 {{序列号}}
```

## 6. 交付范围（一次交齐，禁止「后续缩水包」）

> 实施任务 Task 1–26 见 `docs/superpowers/plans/2026-10-20-phase0-1-core-serial-claim.md`。  
> Task 顺序只表示建造先后，**不表示可以砍掉后半段能力。**

**本计划必须全部交付：**

账号密码 + **企微 OAuth**、工作区/成员、Base、Sheet/Field/Record、**Canvas 网格**、筛选/分组/排序/行高/填色、字段全量+HyperFormula、Excel、收集表单（封面/显示条件/二维码）+成功页变量、自动化六动作（limit=1，含指定内容/月额度/日志）、内容权限（行列表）、仪表盘+分析报告+**定时推送**（ECharts）、文件夹/模板、序列号 E2E、跨工作区共享、公开只读、Open API/Webhook、审计与配额、同步（HTTP+文件）、性能底座（索引/队列/OTel/K8s）+ **压测达标报告**、Docker Compose、方案 §9 文档包。

| 验收 | 标准 |
|------|------|
| 一领一码 | 提交 1 次只占 1 条未领 |
| 成功页 | 直接显示本次序列号（码库占用结果） |
| 并发占码 | 不重码（含重试幂等）；高压测零重复 |
| 码发完 | 明确提示、无脏写 |
| 网格 | Canvas；千万行门槛见 PERFORMANCE.md |
| 平台 | 跨空间共享 / 公开只读 / Open API / 同步 / 配额均可用 |
| 登录 | 账号密码与企微 OAuth 双路径（OAuth 可配置关闭，实现不可缺） |
| 扩展 | queue/sync；加副本占码仍正确 |

## 7. 非功能要求

| 类别 | 要求 |
|------|------|
| 性能 | 可扩展至约百万并发填表；单表约千万行顺滑；体感明显快过企微智能表格 |
| 安全 | 工作区隔离；表单外链范围/有效期；附件鉴权 |
| 可靠 | 自动化至少一次 + 幂等；占码事务化 |
| 可观测 | 运行日志、失败告警、关键 API 指标 |

## 8. 明确不做（产品边界，不是延期）

- 不以飞书 / Airtable 为产品或交互对标  
- **不做**复杂 CRDT 多人实时编辑  
- **不做**可编辑公网外链（**要做**公开填表 + 公开只读）  
- **不做**多区域多活  
- **不做**短信验证码（非企微对标刚需；手机号字段与去重仍做）

## 10. 总结

- **只对标企业微信智能表格**；体验与能力以其截图与功能为准。  
- 私有化、多工作区隔离/共享/公开；自研，不 fork。  
- **必须强过企微短板**：成功页出动态结果、`limit=1`、并发占码；性能可扩展且不准降级。

## 已定结论（优化时勿回退）

| 项 | 结论 |
|----|------|
| 路由 | **维持双路由**：目录 `/`（`HomeView`）与工作台 `/workspaces/:ws/bases/:base`（`BaseShellView`）。**不做**单壳 `/?ws=&base=` 合并。 |
| 成员 | **工作区级**能力；入口放在工作区语境（标题旁 / 工作区 ⋯ / 工作区▾），**不放全局顶栏**右上。 |
| 顶栏（目录） | 宜保留全局：消息、账号；勿堆工作区专属入口。 |
| 顶栏（工作台） | 表级：评论、内容权限、公开视图、自动化、导出等；回目录用面包屑。 |
| 目录列表元数据 | **不展示**列数/行数；优先名称、描述、更新时间。 |
| 暂缓 | 断网/离线/实时协作/同步（见 `docs/REMAINING-GAPS.md`）。 |

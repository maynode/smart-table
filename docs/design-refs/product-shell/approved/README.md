# 定稿（已审核）

> 只放 **你已看过并明确说「定稿」** 的示意。  
> 未点头的稿件放在 `../current/` 或 `../full-map/`，不要放进这里。  
> **定稿 = 交互/UI 优化的开发许可证**；定稿前不按示意改代码。功能仍以现网为准，不借定稿加功能。

## 怎么用

1. 新稿 / 讨论稿 → `../current/`（或 `full-map/`）——可反复改，不开发  
2. 你审核通过、说定稿 → 把文件 **移入本目录**（可改名 `01-xxx.jpg`），并在下方「清单」补一行  
3. **仅对本目录已列项** 开前端打磨 PR/改动  
4. 被替代的旧定稿 → 移到 `../archive/`，并改清单状态  

本目录为空：只维持现网，继续讨论即可。

## D. 场景串联（序列号领取）

便于对照产品验收：

1. **码库** 表：序列号、状态(未领)、领取时间、手机号  
2. **收集表单**「序列号领取」：编辑态配字段 → 填写态交手机号 → 分享外链可企业内外填写  
3. **成功页**：企微仅「已提交 / 再填一次」（静态）；我方要在此页直出序列号  
4. **自动化「联动修改」**：表单新增且手机号非空 → 码库查找（状态=未领；未找到则终止）→ **修改「第2步查找的记录」** → **发消息**把第3步序列号推给填写者  
5. **权限**：可对码库/表单/仪表盘/报告分别设档位与行列表细权  
6. **仪表盘**：可按码库「状态」聚合柱状/折线；可定时把仪表盘推给文档成员  

我方相对企微必强：成功页直接展示序列号、查找 limit=1、并发占码；性能与私有化另述产品文档。

# UI 功能打磨清单

> 用途：按页面功能逐项打磨；一项满意后勾选。  
> 原则：边讨论边改，不顺手扩 scope。  
> 对照：`docs/REMAINING-GAPS.md`（能力是否落地）；本文件只管**体验/交互/视觉**是否打磨到位。  
> 更新：2026-10-23

### 产品立场（打磨时遵守）

- **功能面**：已按企微网页版智能表格对齐；缺能力仍以 `REMAINING-GAPS` 为准，不在本清单里「再造功能」。
- **交互 / 样式**：**不强制孪生企微 UI**。若有更清晰的信息架构、更松的密度、更稳的反馈、更顺的动效，可以改——以「更好用、更好看」为准，而不是「长得像」。
- **底线**：保留产品语义与主路径（表 / 表单 / 视图 / 自动化 / 仪表盘 / 权限等）；大改视觉前先口头对齐方向，再动手。

**建议顺序：** ① 收集表单 → ② 网格 → ③ 自动化 → ④ 仪表盘 → ⑤ 首页/壳层 → ⑥ 权限协作 → ⑦ 分析报告 → ⑧ 登录/公开页

## 10. 不纳入本清单

以下已下线或明确暂缓，**不勾、不打磨**：

- 跨工作区共享、群聊、企微登录、同步、开放 API/密钥、配额面板
- 多人实时协同（OT / WS）
- `/dev/grid-bench`（开发压测台）

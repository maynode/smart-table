# 模板：序列号领取

内置「序列号领取」模板，一条命令生成可直接演示/二次开发的完整闭环。

## 1. 安装

```bash
pnpm --filter api seed:serial-claim
```

幂等：Base 已存在时返回现有表单与分享链接，不会重复建数据；输出同时写入 `.data/serial-claim-seed.json` 供 Playwright/冒烟脚本读取。

## 2. 生成内容

- 工作区「序列号领取演示」
- Base「序列号领取」
  - 工作表「收集表单」：手机号（必填）、备注
  - 工作表「码库」：序列号、状态（未领/已领）、领取手机号、领取时间
  - 100 条码：`DEMO-0001` … `DEMO-0100`，初始「未领」
  - 表单「序列号领取」：公开分享、成功页模板、默认开启手机号防重
  - 自动化「联动修改：领取序列号」：
    - 触发：收集表单新增记录且手机号非空
    - 查找：码库中状态 = 未领，`limit` 默认 1，`onFindEmpty=stop`
    - 修改：状态 → 已领（选项 id `claimed`）、领取手机号 ← 表单手机号、领取时间 ← 今天
- 演示账号：`demo@smart-table.local` / `Passw0rd!123`

## 3. 使用

1. 登录后进入 Base，左侧「收集表单」可编辑名称、必填、成功页模板、分享开关、手机号防重。
2. 保存后展示分享链接与二维码；也可以直接访问 seed 输出的 `shareUrl`。
3. 打开链接 → 填手机号 → 提交 → 成功页显示真实序列号。
4. 顶部「自动化」查看运行日志（成功/失败/跳过、耗时、命中记录）。
5. 「码库」中对应记录变为已领，并写入领取手机号与日期。

## 4. 自定义

- 成功页：在表单构建器里改模板，如 `你的兑换码：{{序列号}}`；未知变量原样保留。
- 更多动作：给自动化追加「发消息」「建群」「拉群成员」「新增记录」步骤（见 AUTOMATION.md）。
- 批量领码：显式设置查找步骤 `limit > 1`；默认仍为 1，避免误改。
- 关闭手机号防重：表单构建器取消勾选，或 `POST /forms/:id` 传 `rejectDuplicatePhone:false`。
- 重置演示：删除「序列号领取」Base 后重新执行 seed（会生成新的分享 token）。

## 5. 浏览器验收

```bash
pnpm --filter web test:e2e -- serial-claim
```

Playwright 会重新执行 seed，打开分享链接填写唯一手机号，断言成功页出现 `DEMO-####`，再登录演示账号打开自动化面板，断言存在一条 `success` 运行记录。
